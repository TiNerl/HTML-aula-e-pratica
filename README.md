# SociaLite

## Visão Geral
Este projeto é resultado de uma aula focada nos fundamentos do HTML: estrutura básica (DOCTYPE, indentação padrão), metadados e navegação via links internos e externos.

## Tópicos Abordados
- Comentários HTML
- Tag HEAD e Metadados
- Tag Title
- Identação Padrão (DOCTYPE)
- Elementos Âncora (`<a>`)
- Caminhos Absolutos vs Relativos

## Arquitetura
O projeto está organizado no diretório `frontend/web`, que contém todos os recursos da página web:
- **HTML**: Estrutura semântica com cabeçalho, navegação por âncoras internas (`#home`, `#sobre`), seção sobre o projeto e rodapé com links externos para GitHub e Twitter.
- **CSS**: Estilização centralizada em um container de largura máxima, separadores visuais e itens de navegação dispostos horizontalmente.
- **JavaScript**: Script mínimo que registra no console quando a página é carregada com sucesso.

## Atividade
Criar uma página utilizando todas as tags citadas e modificar seus atributos conforme os requisitos da aula.
